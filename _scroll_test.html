Does !important defeat the modal scroll lock?

All four CSS rules below are lifted verbatim from index.html at 23a2b00. Measured with getComputedStyle in this browser — not reasoned about.

Band-aid ruleModal open
body.style.overflow='hidden'		 computed
overflow-y		Scroll lock
Why row 3 is the one that matters for regression risk. The base rule sets overflow-x:hidden on body. Per the CSS overflow spec, when one axis is hidden the other axis cannot remain visible — it computes to auto. So the question row 3 answers is whether removing the band-aid could ever make the hub unscrollable from CSS alone.
