Shirts — settled

Twelve drawn, eight from photographs. Scottie, Beto, Nick and Jacob have generic faces — Theo settled that on 3 Aug, so they are no longer placeholders waiting on a photograph and the labels no longer say “stand-in”. What Theo described is real on all of them: Scottie’s cap, stubble and logo tee, Beto’s black lead tee. Only the face proportions are invented. Every set of features is fixed, not randomised at run time: a face that reshuffled on every reload could never be approved, and would differ between this sheet and the spread it lands on.

Curtis has the vest and the clipboard — he is the PM, so he is the only one carrying either. The vest is lime, not orange: the red ridge mark computes 3.97:1 against this lime and all but disappears on hi-vis orange. The clipboard runs off the bottom cut on purpose, the same way the shirt does, so it reads as continuing rather than as a cropped rectangle.

Beto is the crew leader, and the only person on the roster in the black lead tee. The third swatch in the shirt row is the shirt reference — same face across all three so the shirt is the only variable — not a second Beto.
